2. Find What You Want to Change

A complete quick-lookup directory mapping every visual, gameplay, audio, and monetization feature to its asset path.

I want to...Start here
Replace images and fontsAssets/2d Art and the relevant UI prefab
Add item definitionsAssets/Data/Items
Edit level contentLevel Generator & Editor tool
Find saved levelsAssets/Prefabs/Levels
Find the level listAssets/Data/Levels Database/LevelDatabase.asset
Change shelf graphicsAssets/Prefabs/Shelves
Change common item appearance settingsAssets/Prefabs/ItemPrefab.prefab
Change a screen or popupAssets/Prefabs/UI Panels
Change booster settingsAssets/Data/Boosters
Change coins and livesPlayer Data component on the game manager
Change product rewardsAssets/In-apps/Products
Find the shop product listAssets/In-apps/IAPDatabase.asset
Change soundsAssets/SFX/AudioCollection.asset
Tip

Select an assigned field in the Inspector to locate the asset it uses. This is useful when you are unsure which prefab or data asset is active.
