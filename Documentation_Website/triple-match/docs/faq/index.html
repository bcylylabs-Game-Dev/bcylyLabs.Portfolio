18. Common Questions (FAQ)

Answers and troubleshooting solutions for common questions regarding items, level generation, boosters, database sync, and saving.

Question 0

My new item does not appear in the palette.

Make sure an Item Data asset was created under Assets/Data. Check its Icon, then refresh the palette. An imported image alone is not an item definition.

Question 1

My new item does not appear in an old auto level.

Check that level's saved item pool and selected range. It may still use the old pool. Random selection also does not guarantee every item appears in one run.

Question 2

Different-looking items are matching as the same type.

Check Item Id values. Each distinct item type needs its own identity. Do not duplicate an Item Data asset and leave its ID unchanged when creating a new type.

Question 3

My item looks too large, small, or low on the shelf.

Compare the sprite's transparent margins, pivot, and Pixels Per Unit with the old art. Then check ItemPrefab auto-fit settings and shelf slot offsets. Check front and deeper layers.

Question 4

My manual level cannot be completed.

Check that every item type has a count divisible by three, that the player has room to move, and that locks/restrictions do not block essential items. Run validation and the solver, then playtest.

Question 5

I painted items, but the level changes when I start it.

Check Distribution Mode. Auto Distribute creates its content from settings. Use Manual for a painted arrangement you want to keep.

Question 6

My level is missing or the wrong level starts.

Check Save Prefab, the Level Number, the numbered prefab, and the database entry. Click Sync DB if needed. Check Enable Test Level and saved progression too.

Question 7

I changed the database order, then it changed back.

Sync DB rebuilds order from the numbered prefab files. Keep the numbering and database consistent for a lasting change.

Question 8

My edits disappear when I stop the game.

You probably changed a running scene object in Play Mode. Stop Play Mode first and edit its saved scene or prefab. Use Save Prefab for the Level Editor's working copy.

Question 9

I changed starting coins, lives, or booster stock, but the old value remains.

Those starting settings are used when no saved value exists. Test with a fresh profile or an intentional test-data reset. Resetting player data also removes progress and balances, so keep your normal test profile if you need it.

Question 10

A booster is missing or locked.

Check its registered asset, Active Boosters list, Unlock At Level, stock, button's Booster Type, and pre-level card configuration. The button and asset must refer to the same existing type.

Question 11

I changed Default Inventory Count on the booster asset, but the starting stock did not change.

The current Booster Inventory loader uses Initial Count Per Booster for unsaved stock. It also restores saved counts. Use that component's starting setting and a fresh test profile.

Question 12

I changed the shelf prefab, but an old level looks the same.

Check whether that level uses a different shelf variant or has a sprite override. Inspect the actual shelf in the level. Test both an existing level and a newly generated one.

Question 13

A button has an empty On Click list, but still works.

Many supplied components connect buttons when the game starts. Check the owning component before adding another event, or the action may run twice.

Question 14

My product asset exists, but no new shop card appeared.

The database registers reward data. It does not automatically build new shop cards. Create or duplicate a card, update its visible content, and connect its matching registered purchase product.

Question 15

I changed the fallback price, but the real price is different.

Fallback Price is display data. It does not set the store price.

Question 16

I changed Base Level Reward, but the normal win still gives the same base amount.

The normal game flow supplies 100 when opening the completion popup. That supplied value takes priority over the popup fallback. See Level completion rewards.

Question 17

Where should I start with a full rebrand?

Change the name and icon, then the loading/home screens, item sprites, shelf graphics, popup artwork, and sounds. After that, create one sample level and check the full game flow. Once the sample looks right, continue with the rest of the content.

Ready to customize

Run the main scene, make one small change, save it, and test it. Use the task table near the start of this guide whenever you need to find the next setting.
