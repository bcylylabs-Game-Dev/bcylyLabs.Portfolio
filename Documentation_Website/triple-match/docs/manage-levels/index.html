7. Edit & Manage Levels

Modify existing levels, duplicate variations, renumber levels, sync the Level Database, and test individual stages.

Section 7.0

Edit an existing level

  1. 01
    Select it in the Level Editor dropdown

  1. 01
    Check its Distribution Mode

  1. 01
    Step 1

    In Manual mode, edit the items and their layers.

  1. 01
    Step 1

    In Auto Distribute mode, edit the pool, match count, depth, and empty space settings.

  1. 01
    Step 1

    Change shelf layout, modifiers, or time as needed.

  1. 01
    Step 1

    Run the checks, click Save Prefab, and playtest.

Changing from auto to manual is a change in how items are provided. Check and fill the manual layout before saving it as your finished level.

Section 7.1

Make a variation

Use Duplicate in the toolbar. It saves the source and creates a new numbered copy. Change the copy's items, shape, modifiers, or time. Save it again.

Section 7.2

Add or sync level entries

The Level Database is the ordered list used by Level Manager. The editor normally updates it for you. Sync DB scans numbered prefabs and uses their numbers to rebuild the list.

Keep the Level_001, Level_002, and similar naming pattern. A missing number can leave an empty database entry. Sync does not automatically fill missing level numbers.

Section 7.3

Change order or remove a level

For a temporary custom order, you can adjust the database list in the Inspector. However, Sync DB restores the order from prefab numbers. Keep prefab names, Level Number values, and database order consistent for a lasting change. Back up levels before renumbering or swapping them.

Delete Level removes the selected level and shifts later numbers down. It affects more than the visible level. Check the new order afterward, especially if a tutorial or unlock is tied to a level number.

Section 7.4

Scene copy or saved prefab?

Edit the saved level through the Level Editor for regular content work. Changing a temporary running level in Play Mode does not update its saved prefab.
