8. Generate Levels Automatically

Use the Procedural Single-Level Auto-Generator and Batch Generator to create hundreds of balanced stages with difficulty scaling.

8.1 Generate one level

Open Procedural Auto-Generator.

SettingWhat it does
Level NumberChooses the numbered level to generate. Use an unused number for new content.
Time LimitSets the timer; 0 means unlimited.
Distribution ModeChooses saved/manual placement or runtime auto distribution.
Use Random Items from PoolUses random choices from the selected pool.
Item Pool Mode / RangeChooses all items or a limited index range.
Grid presetChooses dimensions from 1 x 1 to 10 x 10. Selecting a preset does not generate immediately.
Use Custom GridLets you set rows and columns separately, from 1 to 10.
Active Grid DimensionsShows the bounding grid. The chosen shape may use fewer shelves.
SettingWhat it does
Shape ArchetypeChooses the shelf arrangement.
Alphabet CharacterChooses a letter when the Alphabet shape is active.
Notches CountChooses how many edge cutouts to use with Random Notches.
Locked ShelvesNumber of locked shelves to add.
Matches Required to UnlockMatches needed before those locks open.
Restricted ShelvesNumber of restricted shelves to add.
Restricted Shelves Can Contain ItemsAllows items inside those shelves.
Stacking DepthMaximum layers per slot.
Guaranteed Empty SlotsReserves room for moves.
Total Matches / Auto-Fit MatchesSets the requested groups of three or fits the capacity.
Horizontal / Vertical SpacingChanges the gaps between shelves.
Generate & Bake Custom Level PrefabCreates and saves the configured level.
Shelf overlap scannerChecks saved levels for duplicate or overlapping shelves.

Shape choices: Box, Hollow Ring, Staggered Brick, Staircase, Inverted Staircase, Pyramid, Inverted Pyramid, Left Pyramid, Right Pyramid, Cut-Out Center, Random Notches, Alphabet, and Cross/Plus.

Easy starting recipe: Use an unused level number, a 3 x 3 grid, Box shape, Auto Distribute, no modifiers, depth 1, several empty slots, and 90 seconds. Generate it, open it in the Visual Designer, check it, and playtest.

Generating into an existing level number can replace its content. Check the number before generating.

8.2 Generate a batch

Open Batch Generator. Start with a small unused range so you can check the results before making a large set.

SettingWhat it does
Start Level / End LevelThe inclusive range to create. For example, 20-24 creates five levels.
Progression Scaling ModeChooses how difficulty changes across the range.
Global ContextUses each level's position in the whole planned game. Useful for adding a small batch to a longer game.
Total Game Levels ContextThe total planned level count for Global Context.
Batch RelativeRuns from easy to hard inside this batch.
Custom RangeUses your selected start and end difficulty.
Start / End DifficultyValues from 0 to 1. A value of 0.3 means 30% of the generator's difficulty scale.
Distribution ModeChooses Manual or Auto Distribute.
Use Random Items from PoolEnables random item choices.
Sawtooth PacingAdds harder and easier cycles instead of making every level harder than the last.
Thematic Sub-PoolsUses smaller item groups as progression changes.
Item Pool ModeChooses All Items or Range. A specific Range bypasses the thematic sub-pool choice.
Start / End Item IndexLimits the usable items.
Grid buttonsEnable the grid sizes the batch may use. Green means selected.
Select Common / Select All / Clear AllQuickly changes the selected grid set.
Use Custom GridAdds custom row and column dimensions.
Allocation Mode: RandomChooses grids from the active set.
Allocation Mode: Fixed SequenceAssigns a planned number of levels to each selected grid size.
Fixed distribution timelineDrag its dividers, use count controls, or Rebalance Evenly to change how many levels use each grid.
SettingWhat it does
Shape togglesChoose which shape types are allowed.
Notches Count / Alphabet CharacterConfigure the relevant shape.
Select All Shapes / Unselect All / Reset to DefaultsQuickly changes the allowed shapes.
Min Matches (Early) / Max Matches (Late)Controls the early-to-late item workload.
Min Time (Fast/Boss) / Max Time (Relaxed)Sets the available timer range.
Min Empty Slots (Late) / Max Empty Slots (Early)Gives later levels less movement room and early levels more room.
Min Stacking DepthSets the minimum starting depth for generation.
Modifier Allocation Mode: DensityCalculates modifier counts as a percentage of shelves.
Modifier Allocation Mode: RangeUses a minimum and maximum shelf count.
Randomize Modifier PositionsSpreads modifiers across different shelves.
Allow Locked ShelvesIncludes locks using the density or count range.
Allow Restricted ShelvesIncludes restricted shelves using the density or count range.
Restricted Shelves Can Contain ItemsLets generated restricted shelves hold items.

Set spacing, check the level range, then press Generate. After generation, inspect a level near the start, middle, and end of the batch. Run checks and playtest them.

Generation uses several settings together. More items, more depth, fewer empty spaces, and more locks can all increase difficulty. Change a few settings at a time.

8.3 Options tab

OptionWhat it does
Starting Level NumberFirst level number for the alphabet/number batch.
Auto-Detect NextStarts after the last detected level.
Item DistributionChooses Manual or Auto Distribute.
Generate (Minimum Shelves)Creates compact letter and number layouts.
Generate (Regular)Uses the regular 5 x 5 bitmap layout style.
Re-align All Level DepthsUpdates saved item depth positions and related setup across baked levels.
Fast Scan Overlapping ShelvesReports duplicate or overlapping shelf positions.
Clean Duplicate Shelves in PrefabsRemoves duplicate shelves from saved level prefabs.

The alphabet/number batch creates 36 layouts: A-Z and 0-9. Maintenance tools can change many saved levels. Use them when needed and keep a backup first.
