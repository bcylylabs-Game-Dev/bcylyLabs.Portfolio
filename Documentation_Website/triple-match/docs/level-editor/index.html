5. Understand the Level Editor

Master the 4 Level Editor tabs, toolbar actions, level configurations, 2D/3D cabinet layouts, and solvability validation.

Open Tools > Bcyly Labs > Triple Match item sorting kit > Level Generator & Editor.

5.1 The four tabs

TabUse it for
Visual Designer & InspectorBuild or edit one level by working with shelves and items.
Procedural Auto-GeneratorGenerate one level from settings such as size, shape, and item count.
Batch GeneratorGenerate many levels with a difficulty progression.
OptionsGenerate alphabet/number layouts and run project-wide level maintenance tools.

These tabs are different from Distribution Mode, which decides how a level receives its items.

5.2 Top toolbar

ControlWhat it does
Open PrefabOpens the selected level's saved prefab in Prefab Mode.
Level dropdownSelects a level to edit.
Prev / NextLoads the previous or next level.
Sync DBRebuilds the level database from numbered level prefabs on disk.
+ New LevelCreates the next level with a starting layout. You can then change it.
DuplicateSaves the current level, then creates a copy with the next level number.
Delete LevelDeletes the selected level and renumbers the later levels. Read the confirmation before continuing.
Save PrefabSaves your working level and updates its database entry.
PlaytestStarts a test of the selected level in Play Mode.
Save before changing levels or closing the editor.

The visual editor works on an editing copy. Use its Save Prefab button to store your work.

5.3 Level configuration

OptionWhat it means
Level NumberThe level's number. Saving uses a name such as Level_001.prefab. Keep it consistent with the level you intend to edit.
Distribution Mode: ManualUses the item layout you place in the editor.
Distribution Mode: Auto DistributeCreates items from the level settings when the level starts.
Use Random ItemsEnables random item selection for auto distribution.
Guaranteed Empty SlotsReserves room for moving items during distribution.
Depth Per SlotMaximum number of item layers in a slot for distribution. A value of 2 allows a front layer and a layer behind it.
Total MatchesRequested groups of three for generated content. For example, 8 matches means 24 items.
Auto-Fit MatchesSets the match count to fit the calculated capacity.
Capacity informationShows shelves, slots, and the estimated maximum item capacity.
Item Pool Mode: All ItemsUses all items available to the tool.
Item Pool Mode: RangeUses only the selected item index range.
Start / End Item IndexThe first and last item indexes in that range. Check the displayed item names.
Time LimitSeconds available to finish. 90 means 1 minute 30 seconds. 0 means unlimited time.

In Manual mode, your painted items define the layout. Editing Total Matches alone does not paint more items. Use the balance matrix to check the actual placed items.

5.4 Item Palette and painting

ControlHow to use it
SearchFind an item by its name.
Refresh iconReload Item Data from disk. Use it after creating items.
Item thumbnailSelect the item as your active brush.
Layer dropdownChoose Layer 0 (Front), Layer 1 (Back), or Layer 2 (Deep Back).
EraserClears items from clicked slots. Right-click is also a clear action.
Items per pageChanges how many thumbnails appear on one page.
Prev / Next below the paletteMoves between item pages.
Active Brush messageShows which item and layer you are editing.

Select an item, select the layer, then left-click a slot. Check the front and deeper layers when you edit an existing level.

5.5 Cabinet layout controls

Use the cabinet area below the palette in the same screenshot.

ControlWhat it does
Add First RowStarts the layout when no shelves are present.
+ Add ColAdds another column.
Column arrowsMove a column left or right.
X beside a columnRemoves that column.
Row Up / DownChanges the row order.
Row DeleteRemoves the row and its shelves.
+ Fill ShelfAdds a shelf in an empty grid cell.
+ Add Row (Full Width)Adds a row across the current width.
Re-align Cabinet Spacing & ScaleRepositions the shelves using the layout settings.
Reshape rows / columns and Apply ReshapeChanges the cabinet arrangement. Check the whole layout afterward.
Horizontal SpacingChanges the space between columns.
Vertical SpacingChanges the space between rows.
Reset Spacing (Default)Restores the tool's spacing values.
Lock icon on a shelfAdds or removes the shelf lock.
Required match count near a lockSets how many matches are needed to unlock it.
Restricted icon on a shelfAdds or removes the shelf restriction.
Hold ItemsLets a restricted shelf contain items when enabled.

Small spacing values can make shelves overlap. Use Reset Spacing if you need a clean starting point. The current reset values are about 0.406 horizontally and 0.333 vertically; the middle of the slider is not the exact reset value.

5.6 Check the level

  • Re-Check: Updates the validation result.
  • Simulate & Verify: Runs the level solver check.
  • Item Triplet Balance Matrix: Shows counts for each item type in a manual layout. Counts should form complete

groups of three.

For example, 3 apples and 3 bananas form two complete matches. Four apples leave an extra apple.

A validation result is useful, but always play the level too. Check the timer, readability, difficulty, and whether the moves feel clear.
