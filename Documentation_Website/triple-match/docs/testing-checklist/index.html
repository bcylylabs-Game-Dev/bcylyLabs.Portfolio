17. Test Your Changes (Checklist)

An exhaustive quality assurance checklist covering UI, levels, items, boosters, economy, ads, and audio before publishing.

Use this checklist after a content or rebranding pass.

  • Open the main scene and run through Loading, Home, and Level Start.
  • Check the new name, icon, logo, backgrounds, buttons, and fonts.
  • Check the UI at phone and tablet screen sizes.
  • Check new items on the front layer and behind other items.
  • Verify that each manual item count forms complete groups of three.
  • Save and playtest every hand-built level.
  • Check the beginning, middle, and end of a generated batch.
  • Check that the database has the intended order and no missing entries.
  • Test locks, restrictions, movement, and obstacles used by your levels.
  • Test pause, resume, restart, return home, win, failure, and continue.
  • Check booster icons, unlock levels, stock, and pre-level selection.
  • Test lives recovery and Out of Lives options.
  • Test product reward amounts and the visible shop card information.
  • Check the existing ad triggers and rewarded results.
  • Check music, effects, and mute toggles.
  • Turn off test-level mode, skip shortcuts, infinite boosters, and preview overrides you used for testing.
  • Save the scene and all edited prefabs.
