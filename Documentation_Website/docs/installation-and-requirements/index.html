Installation & Requirements

UPFS is delivered as a Unity Asset Store package. Import the package, allow Unity to compile its runtime and Editor assemblies, then create the Upgrade ScriptableObject that will own your first progression.

Project requirements

The framework uses standard Unity ScriptableObjects, Editor scripting, UnityEvents and PlayerPrefs.

  • A Unity project compatible with the version declared on the current Asset Store listing
  • No third-party Inspector or serialization dependency
  • Write access to PlayerPrefs when using the included persistence behavior
  • Unity UI or UI Toolkit only when your own runtime interface requires it
Information · Render-pipeline independent

The core framework is data and Editor tooling. It does not depend on Built-in, URP or HDRP rendering features.

Import the package

  1. 01
    Open Package Manager

    Choose Window › Package Manager and open My Assets.

  2. 02
    Find UPFS

    Select Ultimate Progression Framework System and download the current release.

  3. 03
    Import

    Import the framework folders and wait for Unity to finish compiling.

  4. 04
    Confirm the Create menu

    Right-click in the Project window and locate Bcyly Labs › Ultimate Progression Framework.

Important · Resolve compile errors first

Unity custom Inspectors load only after the project compiles successfully. Existing errors elsewhere in the project can prevent the UPFS Inspector from appearing.

Core package structure

Runtime components are separated from professional Editor tooling.

AreaContentsBuild inclusion
UpgradeUpgrade data and UpgradeListenerRuntime
CurrencyCurrency data and CurrencyListenerRuntime
EconomyUpgradeEconomyHandler and listenerRuntime
InfoUpgradeInfoProvider metadataRuntime
EditorInspectors, settings and PlayerPrefs toolsEditor only
