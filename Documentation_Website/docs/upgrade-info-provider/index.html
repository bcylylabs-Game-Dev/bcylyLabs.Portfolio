Upgrade Info Provider

Upgrade Info Provider transforms Upgrade SO data into a UI-friendly information layer. Select the built-in fields your interface needs, add typed custom fields, and query one consistent source at runtime.

Inspector section

1. Upgrade Source & Sync

Connects the provider to the authoritative Upgrade SO and controls synchronization.

Fetch Upgrade Info reads the nested Big and Small Upgrade structure and creates a presentation record for each step.

Use preserveExisting when refetching after structural edits if existing custom values should remain attached where possible.

Warning · Refetch after source changes

When groups, levels or ordering change in Upgrade SO, refetch the provider before relying on indexed information at runtime.

Inspector section

2. Field Selection

Chooses which standard Upgrade fields are copied into the information layer.

  • Big and Small Upgrade names and indices
  • Upgrade level, value and native price
  • Completion and current-state information
  • Fields used by cards, tooltips, previews and selection screens
Tip · Keep payloads intentional

Select the fields your presentation layer actually uses. This keeps the Inspector easier to review and the data contract explicit.

3. Custom Field Definitions

Adds project-specific presentation metadata without modifying Upgrade SO.

Field typeTypical purposeExample
StringLabels and descriptionsIncreases attack speed
Int / FloatAdditional numeric metadata+15 or 1.25
ColorRarity and visual stateLegendary accent
SpriteIcons and badgesTier emblem

Texture2DLarge art or previewsUpgrade artwork
Information · Scope controls placement

SmallOnly stores a value for individual steps, BigOnly stores a group-level value, and Both makes the definition available at both levels.

Inspector section

4. Fetched Upgrade Data

Shows the synchronized presentation records and their custom values.

Important · Treat names and indices as authored contracts

If runtime code queries by name or index, keep those identifiers stable or update consumers alongside the data.

Runtime queries

Read the current, next or specifically indexed presentation record.

  • GetNextUpgradeInfo
  • GetUpgradeInfo by global or Big/Small index
  • GetAllInfoForBig and GetBigUpgradeInfo
  • GetCustomField and GetCustomFieldByIndex overloads
  • CheckDirty for synchronization monitoring
csharp
UpgradeInfoProvider.SmallUpgradeInfo next =
+    infoProvider.GetNextUpgradeInfo();

if (next != null)
{
    UpgradeInfoProvider.CustomFieldValue label =
+        infoProvider.GetCustomField(next, "display-name-tag");

    Debug.Log(label.stringValue);
}
