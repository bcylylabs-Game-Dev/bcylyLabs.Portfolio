Editor & Workflows

Framework Settings

Framework Settings centralizes Editor preferences for Upgrade, Currency, Economy and Info Provider workflows. Use the global controls as your baseline, then review the component-specific options that affect authoring and synchronization.

Settings section

1. Global Settings

Controls shared Inspector behavior, confirmations and framework-wide authoring preferences.

Tip · Team consistency

Agree on settings that alter automatic behavior before several team members begin authoring shared progression assets.

Settings section

2. Upgrade Settings

Configures Upgrade Inspector conveniences, generation behavior and development safeguards.

Settings section

3. Currency Settings

Controls Currency SO Inspector and persistence-development preferences.

Settings section

4. Economy Settings

Configures Economy Handler fetching, data distribution and synchronization behavior.

Warning · Automatic fetches can replace generated output

When enabling automatic synchronization, verify custom cost edits after structural changes to the source Upgrade.

Settings section

5. Info Provider Settings

Controls Info Provider synchronization and custom metadata authoring behavior.
