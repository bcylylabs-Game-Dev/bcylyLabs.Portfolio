Economy & Info API Reference

Upgrade Economy Handler and Upgrade Info Provider are optional read-and-action layers around Upgrade SO. Economy owns payment decisions; Info Provider owns UI-oriented metadata.

Economy synchronization

SignatureBehavior
FetchUpgradeInfo()Rebuilds flattened economy entries from the assigned Upgrade SO
DistributeAllCurrencies()Generates every configured currency cost series
IsFullyUpgraded()Delegates completion state to the linked Upgrade

Cost and affordability queries

SignatureReturns
GetNextUpgradeCost(string currencyName)Next cost for a named currency
GetNextUpgradeCost(int currencyId)Next cost for a Wallet Currency ID
GetUpgradeCost(int globalIndex, string currencyName)Named cost at a flattened index
GetUpgradeCost(int bigIndex, int smallIndex, string currencyName)Named cost at nested indices
GetUpgradeCost(..., int currencyId)Equivalent ID-based overloads
CanAffordNextUpgrade()Whether the current payment mode can pay for the next step
CanAffordUpgrade(int globalIndex)Whether any valid Wallet option can pay
CanAffordUpgrade(int globalIndex, Currency chosenCurrency)Whether the supplied Currency can pay

Selection, progress and Buy Max

SignatureReturns

GetProgressToNextUpgrade(int currencyId)ID-based equivalent
GetAffordableUpgradeCount(string currencyName)Sequential upgrade count affordable by name
GetAffordableUpgradeCount(int currencyId)Sequential upgrade count affordable by ID

Purchase methods and results

  • success
  • failReason
  • currencyUsed
  • amountDeducted

Custom field lookup

SignatureLookup
GetCustomField(SmallUpgradeInfo info, string tag)Small field by stable tag
GetCustomField(BigUpgradeInfo info, string tag)Big field by stable tag
GetCustomField(int globalIndex, string tag)Small field at flattened index
GetCustomFieldByIndex(SmallUpgradeInfo info, int fieldIndex)Small field by definition order
GetCustomFieldByIndex(BigUpgradeInfo info, int fieldIndex)Big field by definition order
Tip · Prefer stable tags

Tag-based lookup is clearer and more resilient than field-index lookup when custom definitions may be reordered during development.
