Core Components

Listeners & Events

UPFS exposes C# events on its data assets and listener components for Inspector-driven UnityEvent workflows. Use either approach independently or combine them according to the architecture of your project.

Component

Upgrade Listener

Routes Upgrade SO progression events from a referenced asset into a scene object.

  • Respond to any successful upgrade
  • Receive detailed Big and Small Upgrade context
  • React to Small or Big milestone timing
  • Handle the fully upgraded state
Component

Currency Listener

Routes balance changes, gains, spending, resets and loads into UnityEvents.

Tip · Good UI fit

Use OnValueChanged for balance labels and OnValueDecreased for spend feedback such as particles, sounds or animations.

Component

Economy Listener

Routes successful purchases, failed attempts and full completion events.

Subscribe from code

Use C# subscriptions when handlers need typed data or should remain outside scene wiring.

csharp
private void OnEnable()
{
    gold.OnValueChanged += RefreshBalance;
    economy.OnUpgradePurchased += HandlePurchase;
}

private void OnDisable()
{
    gold.OnValueChanged -= RefreshBalance;
    economy.OnUpgradePurchased -= HandlePurchase;
}
Important · Always unsubscribe

Pair subscriptions and removals in matching lifecycle methods to avoid duplicate callbacks or references to destroyed objects.

Upgrade event order

  1. 01
    State changes

    The next Small Upgrade is marked complete.

  2. 02
    General events

    Any Upgrade and detailed context events are raised.

  3. 03
    Milestone events

    Small or Big Upgrade events fire according to the configured trigger mode.

  4. 04
    Completion

    Fully Upgraded fires when no incomplete step remains.

  5. 05
    Persistence

    The updated Upgrade state is saved.
