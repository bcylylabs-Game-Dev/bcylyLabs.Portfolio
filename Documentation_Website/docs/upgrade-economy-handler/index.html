Upgrade Economy Handler

Upgrade Economy Handler connects an Upgrade SO to one or more Currency assets. It generates per-level costs, evaluates affordability and executes controlled purchases through three payment modes.

Inspector section

1. Upgrade Source & Sync

Links the economy to its authoritative Upgrade SO and copies its current structure.

Fetch Upgrade Info creates a flattened economy entry for every Small Upgrade while retaining its Big and Small indices, level, value and native price.

Warning · Re-fetch after structural edits

Additions, deletions or ordering changes in Upgrade SO are not automatically reflected in previously fetched economy data unless the relevant auto-fetch preference is enabled.

3. Wallet & Payment Settings

Defines which Currency assets can pay and how the payer is selected.

Payment modeBehaviorRequired API
Any OneUses the first affordable wallet currency with a matching costPurchaseNextUpgrade
PriorityUses wallet order as explicit payment priorityPurchaseNextUpgrade
Player ChoiceThe game presents valid options and supplies the selected CurrencyGetAffordableOptionsForNext + PurchaseWithCurrency
Important · Wallet order matters

For automatic selection, place the most preferred Currency first in the Wallet list.

Inspector section

4. Fetched Upgrades Data

Shows the flattened upgrade sequence and generated cost for every currency.

  • Big and Small Upgrade indices
  • Level, value and native price
  • One generated cost entry per configured currency
  • Sequential order used by purchase and Buy Max queries
Tip · Balance before runtime

Review the first, middle and final generated costs to confirm that the selected distribution matches the intended economy curve.
